# Мониторинг топлива — Липецкая область

**Сайт:** https://gas.qantrix.ru

Независимый дашборд по наличию топлива и очередям на заправках Липецкой области. Данные берутся с [официального портала мониторинга АЗС](https://gas-monitoring.admlr.lipetsk.ru/reports/) и обновляются автоматически каждые 5 минут.

## Что можно посмотреть

- **Текущая ситуация** — когда данные обновлялись в последний раз и какая доля АЗС сейчас отдаёт АИ-92, АИ-95 и дизель
- **Когда появилось топливо** — таблица с моментами появления каждого вида топлива по АЗС
- **Динамика** — графики доли АЗС с топливом, наличия по каждой заправке и очередей во времени
- **Последнее состояние** — сводная таблица по всем АЗС
- **Фильтры** — период, регион, бренд, конкретные АЗС и быстрый поиск

Строка статистики вверху показывает общую картину по области и **не зависит** от выбранных фильтров. Графики и таблицы ниже — с учётом фильтров.

## Откуда данные

Источник — открытые отчёты администрации Липецкой области. Сервис только собирает и визуализирует их; за актуальность и полноту отвечает [оригинальный портал](https://gas-monitoring.admlr.lipetsk.ru/reports/).
